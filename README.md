## সাইট চালু করা (GitHub Pages)

1. GitHub → **Settings → Pages** খুলুন।
2. Source = **Deploy from a branch**, Branch = **main** / **/ (root)** → **Save**।
3. ১–২ মিনিট অপেক্ষা করুন → সাইট লাইভ হবে: `https://moniruzjaman.github.io/frg-2024-ebook/`

## GA4 অ্যানালিটিক্স (ঐচ্ছিক)

`js/analytics.js`-এর শুরুতে `const GA_ID = '';` — এখানে আপনার Measurement ID (`G-XXXXXXXXXX`) বসালেই
chapter reads, TTS plays, share clicks (প্রতি প্ল্যাটফর্ম) ট্র্যাক হওয়া শুরু হবে। `anonymize_ip: true` পূর্বেই সেট।
